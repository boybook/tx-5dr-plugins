# CQ Rotation

TX-5DR 多操作员定时 CQ 轮换插件。

## 功能

- **定时轮换**：多个操作员按设定时间间隔轮流发送 CQ 呼叫
- **顺序模式**：按呼号列表顺序依次轮换
- **随机模式**：从呼号列表中随机选择下一个操作员，保证全覆盖后才重复
- **QSO 保护**：轮换时间到达时，若当前操作员正在通联中，会等待通联完成后再切换
- **失败重试**：通联失败时自动重试一次，连续失败 2 次才强制切换到下一个操作员
- **FT8 时序对齐**：轮换计时与 FT8 时隙对齐，确保切换时机准确
- **协调者选举**：多操作员实例自动选举协调者，协调者掉线后其他实例自动接管
- **冲突防护**：轮换运行期间自动抑制自动起呼插件的干扰

## 配置

在 TX-5DR 插件设置中配置以下选项：

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 启用 CQ 轮换 | 开关 | 关闭 | 启用后操作员将按设定间隔轮流发送 CQ |
| 操作员呼号列表 | 字符串数组 | 空 | 参与轮换的呼号列表，顺序模式按此顺序轮换 |
| 轮换间隔（秒） | 数字 | 120 | 每个操作员发送 CQ 的持续时间（15-86400 秒） |
| 轮换模式 | 选择 | 顺序 | 顺序：按列表顺序；随机：随机选择下一个 |

## 快捷操作

插件提供 3 个快捷操作按钮，显示在工具栏中：

- **开始轮换** - 启动 CQ 轮换
- **停止轮换** - 停止 CQ 轮换

## 使用方法

1. 在插件设置中启用插件
2. 输入参与轮换的操作员呼号（空格或换行分隔）
3. 设置轮换间隔和模式
4. 点击"开始轮换"快捷按钮

## 注意事项

- 至少需要配置 2 个呼号才能启动轮换
- 轮换状态在所有操作员实例间共享，设置为全局生效
- 建议同时禁用其他自动起呼插件以避免冲突
